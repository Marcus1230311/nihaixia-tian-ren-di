# 倪海廈醫道傳習網

一個以繁體中文整理天紀、人紀、地紀三條研讀主線的靜態知識網站。V1 的重點是保存、編排並連結既有課程筆記、古典原文、編者導讀與外部補充資料，讓讀者可以依模組循序閱讀。

## 內容結構

- **天紀**：易經、八字命理、河洛姓名與風水基礎。
- **人紀**：黃帝內經、針灸大成、神農本草經、傷寒論、金匱要略。
- **地紀**：堪輿總論、龍穴砂水、羅盤方位、陽宅案例與陰宅基礎。

V1 共 54 個 HTML 頁面：全站首頁 1 頁、天紀 15 頁、人紀 32 頁、地紀 6 頁。網站採原生 HTML 與共用 CSS，不需要後端、資料庫或建置流程即可瀏覽。

## V1 驗證狀態

目前的靜態基線已完成內容與產品品質驗收：

- 54 個頁面均具有唯一標題、摘要與單一 H1。
- 站內連結、頁內錨點、麵包屑及前後篇導覽均已驗證。
- 桌面與 390×844 行動視口沒有頁面級橫向溢出。
- 內容頁保留來源／編輯說明，醫療內容保留研讀用途與安全邊界。
- `node tools/validate-site.js` 會檢查頁數、可達性、結構、來源說明、重複內容與公開狀態文字。

完整驗收紀錄見 [`AUDIT_LOG.md`](AUDIT_LOG.md)，目前缺口見 [`OPEN_GAPS.md`](OPEN_GAPS.md)。

## 來源與內容邊界

本站不是倪海廈課堂的逐字稿。正文可能包含本站既有課程筆記的轉述、古典原文、編者整理，以及明示的外部公共資料；各頁會依資料性質提供說明。穴位、方藥、診斷與治法僅供文獻研讀，不構成自行診療、用藥或操作建議。

## V2 路線

後續將在獨立開發分支逐步遷移為以 Next.js、TypeScript 和 MDX／結構化資料為核心的靜態知識平台，優先建立：

1. 穩定的知識實體與關係模型；
2. 全站搜尋與一致的學習導覽；
3. 可重用的交叉引用；
4. 由資料驅動的卦象、五行、經絡與方藥關係視覺；
5. 可供未來知識圖譜使用的驗證資料層。

V2 遷移以保留 V1 已驗收內容、來源標示、繁體中文呈現及安全邊界為前提，不在 `main` 直接開發。
